プライバシーポリシー

制定日：2026年10月3日

1. このサイトについて

本サイトは、YouTube チャンネル「寝落ち世界史」（以下「当チャンネル」）の運営者が、動画の原稿を公開するために運営している静的なウェブサイトです。本サイトには、会員登録、問い合わせフォーム、コメント機能、アクセス解析、広告、Cookie の利用はなく、閲覧者の個人情報を収集しません。

本サイトは GitHub Pages で配信されています。配信にあたり GitHub, Inc. がアクセスログ（IP アドレス等）を取得する場合があります。詳しくは GitHub のプライバシーステートメントをご覧ください。また、文字の表示に Google Fonts を利用しています。

2. Google API の利用について

当チャンネルの運営者は、動画投稿作業を自動化するため、運営者自身が使用するアプリケーション「claude-video-upload」を利用しています。このアプリケーションは、YouTube API Services（YouTube Data API v3）および Google Sheets API を利用し、次の目的にのみ使用します。

・運営者自身の YouTube チャンネルへの動画のアップロード、タイトル・説明文・サムネイル等の設定、公開日時の予約、投稿状況の確認
・運営者自身が管理する Google スプレッドシート（原稿・投稿スケジュール）の読み取りと更新

アクセスするのは運営者自身のアカウントのデータのみで、第三者のユーザーデータを取得・保存することはありません。取得したデータを第三者へ提供・販売したり、広告に利用したりすることはありません。認証情報は運営者のコンピューター内にのみ保存され、外部に送信されません。Google API から受け取った情報の使用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

YouTube API Services の利用により、本アプリケーションの利用者は YouTube 利用規約に同意したものとみなされます。Google によるデータの取り扱いについては Google プライバシーポリシーをご覧ください。本アプリケーションへのアクセス許可は、Google アカウントのセキュリティ設定からいつでも取り消すことができます。

3. 改定

本ポリシーの内容は、必要に応じて改定することがあります。改定した場合は、このページの内容を更新します。
